# Changelog

All notable changes to this project are documented in the
[GitHub Releases](https://github.com/NightZed/PomodoroLogger-Enhanced/releases)
page — release notes are generated automatically by
[semantic-release](https://semantic-release.org/) for every version tag.

This file is intentionally no longer updated on each release: committing
release artifacts back to the repository is discouraged by semantic-release
(see its [FAQ](https://semantic-release.org/support/faq#should-release-notes-be-committed-to-a-changelogmd-in-my-repository-during-a-release)).
Historical release notes up to and including `v0.14.1` remain available in the
GitHub Releases page.
